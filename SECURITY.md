# Security Policy

## Supported Versions

Please check the repository for the latest supported versions. Currently, only the `main` branch receives security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them by sending an email to security@example.com (replace with project maintainer email).

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.
