# Coding Conventions

## Python Standards
- We strictly adhere to PEP 8 formatting.
- `ruff` is used for linting and formatting. Ensure your code passes all checks before committing.
- `pyrefly` is used for static type checking. All function arguments and return values must be strongly typed.

## Naming Conventions
- **Variables/Functions**: `snake_case`
- **Classes**: `PascalCase`
- **Constants**: `UPPER_SNAKE_CASE`

## Git Workflow
- Feature branches should be named `feature/<feature-name>`.
- Bugfix branches should be named `bugfix/<bug-name>`.
- Commits must use descriptive messages detailing *why* the change was made.
